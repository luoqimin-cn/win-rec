1. 安装说明

第一步：解压程序包

1

将 win-rec-windows.zip 解压到你想要存放的位置，例如：

C:\Users\你的用户名\Desktop\win-rec\

解压后目录结构如下：

win-rec\ win-rec.exe ← 主程序 win-rec-recorder.exe ← 录音子程序（自动调用，无需手动运行） ffmpeg.exe ← 音频处理工具（已内置） ffprobe.exe ← 音频分析工具（已内置） 使用手册.html ← 本文档 （其他依赖文件...）
2

在 win-rec 文件夹内，按住 Shift + 右键，选择 "在此处打开命令窗口" 或 "在终端中打开"。

如果没有这个选项，也可以：

  1. 在地址栏输入 cmd，然后按回车
  2. 或者打开开始菜单，搜索"命令提示符"，启动后用 cd 命令切换到解压目录
3

输入以下命令验证程序正常：

> win-rec.exe --help

如果看到命令列表，说明安装成功。

提示：不需要管理员权限，也不需要安装 Python 或 ffmpeg——所有依赖都已打包在内。

首次运行：下载 Whisper 语音识别模型

第一次使用转录功能时，程序会自动从网络下载 Whisper large-v3 模型（约 3GB）。请确保网络畅通，下载过程需要几分钟，之后无需重复下载。

注意：模型会保存在 C:\Users\你的用户名\.cache\huggingface\，无需管理员权限。

2. 配置 DeepSeek API Key

win-rec 使用 DeepSeek 的 AI 接口来生成会议总结。需要在电脑上设置两个环境变量。

第一步：获取 DeepSeek API Key

  1. 访问 platform.deepseek.com，注册账号并登录
  2. 进入控制台 → API Keys，点击"创建 API Key"
  3. 复制生成的 Key（形如 sk-xxxxxxxxxxxxxxxx）
提示：DeepSeek 提供按量付费，价格远低于 OpenAI。处理一小时会议录音的总结费用通常不超过 ¥0.5。

第二步：设置环境变量（永久生效，只需操作一次）

打开命令提示符（不需要管理员权限），逐行输入以下命令：

:: 第1行：设置 API Key（把 sk-xxx 替换成你自己的 DeepSeek Key） > setx OPENAI_API_KEY "sk-xxxxxxxxxxxxxxxxxxxxxxxx" :: 第2行：指定将请求发到 DeepSeek 服务器（而非 OpenAI） > setx OPENAI_BASE_URL "https://api.deepseek.com" :: 第3行：指定使用 DeepSeek 的 AI 总结模型 > setx AI_REC_SUMMARY_MODEL "deepseek-chat" :: 第4行：使用 OpenAI 兼容的请求格式（DeepSeek 兼容此格式，请求仍发往 DeepSeek） > setx AI_REC_SUMMARY_BACKEND "openai"
说明：变量名中含有"OPENAI"只是因为 DeepSeek 的接口格式与 OpenAI 完全兼容，程序复用了同一套请求格式。实际所有请求都发往 DeepSeek 服务器，费用从 DeepSeek 账户扣除，与 OpenAI 无关。
重要：设置完成后，必须关闭并重新打开命令提示符，环境变量才能生效。

验证配置

重新打开命令提示符后，输入：

> echo %OPENAI_API_KEY%

如果显示你设置的 Key，说明配置成功。

3. 快速开始（录一次会议）

以下是一次完整会议录音的最简操作步骤：

1
会议开始前，启动录音
> win-rec.exe start

看到 Recording started 提示即表示开始录音。

2
会议结束后，停止录音
> win-rec.exe stop
3
生成转录和总结
> win-rec.exe process latest

程序会自动完成：语音识别 → AI 总结 → 保存 Markdown 文件

完成！总结文件保存在 C:\Users\你的用户名\AI_Rec_Data\recordings\日期时间\summary.md

5. 完整使用流程

场景一：普通会议录音

:: 开会前启动录音（可选：给本次录音起个名字） > win-rec.exe start "产品需求评审会" :: 途中临时离开或讨论私密内容时，暂停录音 > win-rec.exe pause :: 回来后恢复 > win-rec.exe resume :: 会议结束，停止录音 > win-rec.exe stop :: 处理最新一次录音（转录 + 总结） > win-rec.exe process latest

场景二：查看历史录音

:: 列出所有录音 > win-rec.exe list :: 重新处理某次历史录音（使用 list 显示的日期时间作为 ID） > win-rec.exe process 2025-01-15_10-00-00

录音文件存储位置

所有录音和处理结果保存在：

C:\Users\你的用户名\AI_Rec_Data\recordings\ 2025-01-15_10-00-00\ mic.m4a ← 原始录音文件 transcript.json ← 详细转录数据 transcript.md ← 带时间戳的转录文本 summary.md ← AI 生成的会议总结 meta.json ← 录音元数据
提示：可以用任意文本编辑器（记事本、VS Code 等）打开 .md 文件查看内容。

6. 高级设置

修改录音数据存储位置

:: 将录音保存到 D 盘（路径中不要有空格） > setx AI_REC_DATA "D:\会议录音"

指定录音语言（加快转录速度）

:: 如果会议全程说中文，指定语言可避免自动检测的延迟 > setx AI_REC_WHISPER_LANGUAGE "zh" :: 英文会议 > setx AI_REC_WHISPER_LANGUAGE "en"

添加专业词汇提示（提高行业术语识别准确率）

:: 例如技术会议中常用的专有名词 > setx AI_REC_WHISPER_PROMPT "Kubernetes, Docker, CI/CD, API, 微服务"

改用 Claude API 生成总结

:: 如果你有 Anthropic API Key，也可以用 Claude 生成总结 > setx ANTHROPIC_API_KEY "sk-ant-xxxxxxxxxxxxxxxx" > setx AI_REC_SUMMARY_BACKEND "anthropic" > setx AI_REC_SUMMARY_MODEL "claude-opus-5"

所有可配置的环境变量

变量名 默认值 说明
OPENAI_API_KEY （必须设置） DeepSeek 或 OpenAI API Key
OPENAI_BASE_URL （空，使用 OpenAI 官方） DeepSeek 设为 https://api.deepseek.com
AI_REC_SUMMARY_MODEL claude-sonnet-4-6 总结使用的 AI 模型，DeepSeek 设为 deepseek-chat
AI_REC_SUMMARY_BACKEND auto 总结后端：openai / anthropic
AI_REC_LOCAL_WHISPER_MODEL large-v3 Whisper 模型大小（large-v3 / medium / small）
AI_REC_WHISPER_LANGUAGE （自动检测） 录音语言：zh / en 等
AI_REC_WHISPER_PROMPT （空） 专业词汇提示，帮助识别专有名词
AI_REC_DATA 用户目录下 AI_Rec_Data 录音数据存储根目录

7. 常见问题

Q: 运行后提示找不到程序，怎么办？

请确保命令提示符的当前目录是 win-rec 文件夹（即 win-rec.exe 所在的目录）。可以在地址栏输入 cmd 直接打开，或使用 cd 命令切换。

Q: 转录很慢，CPU 占用很高，正常吗？

正常。本地 Whisper 转录需要大量计算，一小时录音通常需要 10-30 分钟（取决于 CPU 性能）。转录期间可以继续做其他工作，只要不关闭命令窗口即可。

Q: 第一次 process 时卡住很久不动，正常吗？

正常。第一次使用时需要从网络下载 Whisper 模型（约 3GB），请耐心等待。下载完成后会自动继续处理，以后不需要重复下载。

Q: AI 总结显示 API Key 错误？

请检查：

  1. 设置 API Key 后是否重新打开了命令提示符（必须重新打开才能生效）
  2. 输入 echo %OPENAI_API_KEY% 确认 Key 已正确设置
  3. 确认 Key 本身有效（可以在 DeepSeek 控制台验证）
  4. 确认账户余额充足

Q: 录音没有声音，或者转录出来是空的？

win-rec 录制的是麦克风输入。请检查：

  1. 麦克风是否正确连接并选为默认录音设备
  2. 在 Windows 设置 → 系统 → 声音 → 输入，确认有信号
  3. 会议软件（如 Teams、Zoom）是否独占了麦克风——可以尝试先启动 win-rec，再进入会议

Q: 如何录制系统音频（对方的声音）？

当前版本只录制麦克风输入（你自己说话的声音）。如果需要同时录制对方声音，建议在耳机/扬声器旁放置麦克风，或使用带回声消除的专业麦克风。

Q: 转录结果里有很多乱码或英文，但会议说的是中文？

尝试设置语言提示：

> setx AI_REC_WHISPER_LANGUAGE "zh"

重新打开命令提示符后再次运行 process。

Q: 想删除某次录音，如何操作？

:: 先查看录音列表，找到对应的 ID > win-rec.exe list :: 删除指定录音（会有确认提示） > win-rec.exe delete 2025-01-15_10-00-00

Q: 程序崩溃后无法再 start，提示"已有录音在进行中"？

这是自动恢复机制。再次运行 win-rec.exe start，程序会自动检测并清理上次异常退出的残留状态，然后开始新录音。
